# A short framework demonstration

This is a suggested two-minute sequence for the final challenge demo. It requires only the bundled examples; no live model wait, sign-in or map service is needed.

1. **Explain the record (15 seconds).** “Wordscape is an alpha proposal for carrying a world's structure in a compact JSON document. This application is one way to author and interpret it.” Open Examples → Mossbell Retreat · terrain.
2. **Show the same data in two views (25 seconds).** Switch between Words and 3D world. Select a hut and show its placement, dimensions and authored evidence. “The document specifies what and where; this interpreter chooses how it looks.”
3. **Show actual terrain (20 seconds).** Toggle Flat comparison, then restore terrain. Open Terrain & survey to show the authored grid. “This heightfield travels with the document. Flat comparison changes only the view.”
4. **Show portability (25 seconds).** Open Document and export world JSON. Explain that byte counts include this world's terrain and facts but exclude the renderer and dependencies. Mention the 1,617-byte minimal example as a small format introduction, not equivalent finished-scene compression. Export GLB as the included interpreter's visual output with the source document in metadata.
5. **Show evidence and scope (20 seconds).** Open Examples → Washington Square. Inspect a mapped peripheral building and its height/color evidence. “Real measurements, estimates and authored appearance remain distinguishable.”
6. **Show authoring without making the audience wait (15 seconds).** Open Imagine a world and point to optional brief, real-place references and authored terrain. Close it without generating. “Models return bounded, reviewable data. Another interpreter or agent can implement this published contract.”

End with the repository link and format/contributor guides. State the alpha limits plainly: procedural visuals, variable generated layout quality, approximate walking, and no universal engine support. Do not claim the Three.js view is a photorealistic reconstruction or that an arbitrary generator already consumes the format.
