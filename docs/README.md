# Documentation

Wordscape application **0.9** demonstrates the **0.8 world document format**. The format is an evolving alpha proposal; the workbench and its Three.js scene are reference implementations.

## Start here

- [Run the project](../README.md): local setup, optional model connection and licensing overview.
- [Framework](FRAMEWORK.md): what the document records, what an interpreter decides and where the boundaries are.
- [Demo guide](DEMO_GUIDE.md): examples, editing, terrain, generation and exports using the current controls.
- [Minimal world JSON](../public/examples/minimal.wordscape.json): three manually authored objects, no services or external data.
