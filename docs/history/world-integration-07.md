These are application verification calls made by the root Codex agent during the user's seventh project prompt. They are not extra human build direction. They used the existing official Codex-managed ChatGPT connection in Wordscape's isolated profile, with `gpt-6.1-sol`. No new sign-in, credential copying or separately billed API fallback was used. All three inference calls succeeded; no hidden repair loop or manual model-output correction was used.

Source, terrain, imagery and world-level data were preserved. Each recorded world hash was recomputed from its retained response and matched. Nothing was manually adjusted to make these worlds validate or look better.

## Browser and export check

The final real model output was imported into an isolated Chrome context against the production build. Root inspected desktop orbit, human-scale walking and mobile screenshots. Walking left the document unchanged. Aerial is disabled for the explicit imaginary frame. Its GLB export is 917,340 bytes and includes the complete world document in glTF extras, checked for exact equality; the compact document is about 41.9 KiB. These sizes exclude the viewer and shared procedural interpreter and are not a claim of a new compression algorithm.

The scene is deliberately simple: primitive-based forms and flat ground, with a layout that remains open to further iteration. Validation does not establish perfect realism, route accessibility or suitability for navigation. Three view-level checks plus JSON/GLB preservation do not establish that all possible briefs produce good scenes.

`scripts/world-live-check.mjs create|revise` is an explicit developer command that consumes the selected ChatGPT account's allowance. It never runs in normal tests. It now records the request-specialized schema for future calls. `scripts/world-live-browser.mjs` only replays the retained final document; it makes no inference calls. `scripts/world-generation-smoke.mjs` is a separate deterministic mocked workflow test, not evidence of live generation.

The application uses ephemeral, tool-disabled Codex threads; no persistent app-worker session transcript is created. Requests/responses above, the actual prompt for the final check, server contract, root/subagent dialogue and original root tool traces are retained. Authentication files are excluded from the repository and history.
