## First-build limitations

This is a renderer-independent format experiment and manually interpreted aerial specimen, not automatic image-to-world software. Descriptions are stored and exposed to adapters; the included procedural adapter primarily uses categories and a small tag vocabulary. It does not understand arbitrary natural language. Aerial height/occlusion uncertainty, simplified polygons, flattened terrain and missing small objects remain visible limitations. The document's byte count excludes the viewer, shared procedural generator and aerial reference.
